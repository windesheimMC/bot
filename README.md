# WindesheimMC Discord bot

[![Discord](https://img.shields.io/discord/1422196323507245098?style=flat)](https://discord.gg/kY57mRgKPq)
[![Static Badge](https://img.shields.io/badge/Join-now!-green)](https://windesheimMC.online/)

This is the discord bot that handles most moderaion in the [WindesheimMC](https://windesheimMC.online/) discord server. In the discord server it has the user `WMCBot`. 

## Usage

How can you use this discord bot? Well for one it's not a very universal bot, it is very tailored specifically to the server.

If you really want to however, you can still use it. To do so you must fill out all the values in [`.env.template`](/.env.template) and rename it to `.env`. Then simply run the bot using `node .`.
